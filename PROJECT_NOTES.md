# Project Notes

## Purpose

This independent exercise was prepared to demonstrate Civil 3D modelling, municipal plan/profile production and coordination skills using an anonymized road corridor.

## Included design scope

- Existing-ground terrain model
- Horizontal road alignment and vertical profile
- Road corridor and intersection tie-in coordination
- Storm sewer pipes and structures
- Sanitary sewer pipes and structures
- Plan and profile annotation
- Pipe, structure and station profile bands
- View frames, match lines and sheet-set publishing

## Excluded design scope

- Watermain design
- Final hydrologic or hydraulic certification
- Survey-grade existing utility confirmation
- Geotechnical design
- Traffic engineering and signal design
- Construction quantities, tender specifications and cost estimates
- Permit, approval or record-drawing status

## Review boundaries

The drawings should be understood as a software and design-communication demonstration. A real municipal submission would require current survey, utility records, field investigation, applicable municipal criteria, hydraulic checks, constructability review, interdisciplinary coordination, independent checking and professional authorization.

## Disclaimer

**Conceptual Portfolio Project - Not for Construction.**
